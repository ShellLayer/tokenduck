# 隐私与账号保护

TokenDuck 在本机运行，没有项目方运营的账号服务器、遥测或自动更新服务。额度请求直接发送到代码允许的供应商官方 HTTPS 地址。供应商仍会按其自身政策处理这些请求。

## 会读取什么

- 官方 Codex 登录文件中的访问令牌与账号标识，用于读取额度；不会自行刷新官方客户端的续期令牌。
- Kimi 桌面端结构化登录中的访问令牌。主动启用浏览器连接后，会扫描受支持浏览器本机存储中匹配 Kimi 官方站点的记录，并只采用相应访问令牌，不复制浏览器数据库。
- 本机 ZCode 的套餐配置或加密凭证，用于读取相应套餐额度。
- 您主动提供的已有 Kimi Code、BigModel 或 Z.ai 套餐 key。

不会向您索取账号密码或验证码。官方登录和验证操作由您在官方界面完成。

## 凭证如何保存和使用

本工具自己的会话与手动 key 写入 `accounts.dat`，使用 Windows **当前用户范围** DPAPI 加密。写入使用临时密文文件和原子替换；加载失败时不覆盖原文件。它不是防御同一 Windows 用户下恶意程序的隔离边界。

Kimi 在条件允许时建立独立会话，只刷新自己的续期令牌；导入来源的续期令牌不被借用。无法建立独立会话时，只使用短期访问令牌。已绑定账号自动恢复时保持账号一致；显式换号先验证额度，再替换原绑定。手动 key 模式与网页登录模式不会自动切换。

请求目标限定为代码中列出的官方 HTTPS 主机，跨站或降级重定向在转发认证信息前被拒绝。服务端仍可能撤销登录、修改接口或要求重新验证；加密并不保证会话永久有效。

早期明文凭证只有在加密写入并读回校验后才移除。发现冲突或迁移失败时保留原文件并提示，不覆盖另一个账号。

## 公开设置、缓存和日志

公开设置只保存显示与刷新选项。额度缓存只保留渲染需要的字段与更新时间，不保存访问令牌、续期令牌或 key。

调试日志写入 `%TEMP%\tokenduck_debug.log`，通过 `TOKENDUCK_DEBUG=1` 可启用详细错误记录。错误信息、截图或手动生成的诊断可能包含账号上下文，请在分享前检查并脱敏。不要上传整个数据目录、官方登录文件、Cookie、key 或旧的明文凭证。

数据位置、旧版兼容和卸载方法见[使用指南](USAGE.md)。公开 Git 仓库和发行包不包含本机账号数据。
